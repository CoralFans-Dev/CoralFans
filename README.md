# CoralFans

CoralFans Mod.

## Introduction

CoralFans is a native LeviLamina plugin/mod for Minecraft Bedrock Edition, focused on technical-survival utilities. It provides helper commands and tweaks for redstone, mob spawning, world analysis, and everyday survival QoL, including:

+ HSA display and slime-chunk lookup
+ Village, tick, profiler, and calculation helpers
+ Block/entity data inspection and HUD/container information
+ Block rotate, force-place, force-open, and related tools
+ Auto tool/item/totem and other survival tweaks
+ Free camera, noclip, shortcuts, and minerule options

For detailed command usage, see the [documentation](https://coralfans-dev.github.io/CoralFans-doc/).
